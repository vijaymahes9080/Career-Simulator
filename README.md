# Career Simulator 🚀

> **"Don't ask AI which career you should choose. Simulate the career before you choose it."**

An **AI-Powered Career Decision Intelligence & Future Simulation Platform** designed to model potential career paths, calculate real-time "What-If" scenarios, analyze skill gaps, assess market risks, and maintain a Personal Career Digital Twin.

## 🔥 Key Features & Modules

### 1. 🧪 Interactive "What-If" Lab
- Real-time sliders for **Daily Study Hours** (1–8 hrs/day), **Target Location** (Bangalore, Hyderabad, Mumbai, Remote Global), **Portfolio Projects**, **Internship Status**, and **AI Disruption Toggles**.
- Real-time recalculation of **Job Readiness Score (%)**, **Estimated Learning Timeline** (months), and **Location-Indexed Salary Projections** (Year 0, 3, 5).
- Side-by-side **Scenario Comparison** (Scenario A vs High-Intensity Baseline Scenario B).

### 2. 🗺️ Career Timeline Roadmap
- Visual milestone-by-milestone progression (Month 1–2 syntax fundamentals up to Year 5+ Principal Architect specialization).
- Expandable node details for recommended portfolio projects, skill targets, and phase tags.

### 3. 🎯 Skill Gap Radar & Action Plan
- Percentage gap bars comparing current skills against target role benchmarks.
- Prioritized learning roadmap outlining exact weeks needed to bridge missing skills.

### 4. 🛡️ Multi-Dimensional Risk Engine
- Assesses 5 distinct risk categories: **Competition Density**, **Entry Barrier**, **AI Automation Disruption**, **Skill Volatility**, and **Location Concentration**.
- Contextual explanations ("Why this risk exists") and concrete mitigation strategies.

### 5. ⚖️ Multi-Career Comparison Matrix
- Compare up to 3 technical careers side-by-side.
- Algorithmic **Best Fit Recommendation** highlighting top match score and rationale based on user background.

### 6. 👤 Personal Career Digital Twin
- Live Digital Twin model (`Vijay Mahes - MCA`).
- Interactive **Skill Level-Up Simulator**: Level up any skill (e.g., Python +10%) and watch your Digital Twin recalculate compatibility across all target roles in real-time.

### 7. 🤖 Conversational AI Career Agent
- Plain-English chat assistant answering scenario questions (*"What if I choose Cybersecurity without Linux experience?"*).
- Dynamic responses with recalculated timelines and instant tab navigation.

### 8. 📄 AI Resume & Portfolio Skill Extractor
- Paste resume text or GitHub overview to automatically extract skill proficiencies and sync with Digital Twin.

### 9. 📈 Hiring Velocity & Market Trends
- Multi-year job opening forecasts, remote work adoption rates, and hiring velocity trends.

### 10. 🔀 Career Pivot & Domain Transition
- Simulates switching into tech from non-CS engineering, commerce, or finance degrees with transferable skill scores.

### 11. 🎮 RPG Skill Tree & Quest System
- Gamified tech quest tree with unlockable nodes and XP points.

### 12. 🌐 Global Salary & PPP Calculator
- Compare global compensation standards across SF, London, Bangalore, and Remote markets adjusting for local cost of living.

### 13. ❓ AI Mock Interview Prep Generator
- Practice technical, behavioral, and system design questions tailored to selected career tracks.

### 14. 🎓 AI Mentorship & Learning Resource Guide
- Curated course recommendations, open-source contribution targets, and project guides.

### 15. 💼 Freelance & Gig Economy Simulator
- Models hourly contract rates ($45–$95/hr), client acquisition difficulty, and freelance platform demand.

### 16. 🎓 Official Readiness Certificate Generator
- Exportable/printable Career Digital Twin readiness certificate for resume attachments and academic submissions.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18.x or higher)
- npm (v9.x or higher)

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/vijaymahes9080/Career-Simulator.git
   cd "Career Simulator"
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start development server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser.

4. **Build for production**:
   ```bash
   npm run build
   ```
